## 维护约定

每份报告标注核查日期、研究问题、结论、证据链接与未验证项。
事实引用尽量贴近结论；仓库代码引用固定提交，动态文档记录访问日期。
搜索结果用于定位来源，重要结论回到一手文档或可复现的只读响应。
对无法访问、版本冲突和未做实测的内容直接注明。
文档中的 YAML 示例用于讨论表达能力，未经审定不进入正式数据目录。
保留足够解释上下文的短摘录或定位信息，避免复制完整网页。
原始响应含凭据、账号信息或不明确的再分发内容时，不放入公开仓库。
结论形成后更新 [项目决定](../project/decisions.md) 和 [路线与进度](../project/roadmap.md)。
写 Markdown 时优先每行一句，子目录提供 README 索引，移动文件时同步修正链接。
