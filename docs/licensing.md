## 导入数据与来源材料

根目录的 MIT License 不替第三方 API 响应、模型说明、目录数据或原始快照授予新的使用权。
格式转换、字段规范化或导出为 JSON 不会改变本项目需要保留的上游许可与归属信息。
本仓库目前没有给所有来源数据声明一个统一的数据集许可证。

| 材料 | 当前处理方式 |
| --- | --- |
| models.dev 的导入材料 | 上游仓库提供 MIT License；本仓库保留 [原版权与许可声明](../licenses/models.dev-MIT.txt)，分发相关材料时一并保留 |
| 其他公开 API 的模型目录 | 逐来源核对接口条款、数据许可及再分发范围，不因接口可以公开访问而标记为 MIT |
| 需要凭据的 API 响应 | 本次实现保留适配器与合成测试数据；实际获取和再分发前仍需核对账户权限、条款及数据范围 |
| 人工维护的条件声明 | 保留来源链接、定位、核查日期和审查状态；引用页面的原文仍受其来源条件约束 |
| 原始页面、响应快照与缓存 | 保存与公开发布分别判断，避免把本地留存自动视作公开再分发许可 |
| 模型权重、品牌和图标 | 不由项目代码许可证授权；模型记录中的 license 字段也不能代表本仓库或提供该模型的服务条款 |

models.dev 的依据为 [上游 LICENSE](https://github.com/anomalyco/models.dev/blob/dev/LICENSE)。
该项归属说明不扩展到模型权重、链接指向的页面，或 models.dev 之外的其他来源。

## 新来源的维护记录

纳入新来源时，记录原始地址、许可或条款地址、核查日期、允许保存和分发的范围，以及必须保留的版权或归属声明。
许可范围尚不明确时，在记录中保留这一状态，不用项目的 MIT 标签补全。
对外发布派生数据时同时保留来源、快照引用和适用的上游声明，确保接收者能继续核查来源条件。

本文件说明仓库的许可分工，不认定所有已调研来源都允许任意保存或再分发。
