## 阶段二：用真实资料反向检验 schema

建议仍从文档与手工样本开始。
先选择约 20 个代表性模型版本，数量可按覆盖情况调整；优先让每个样本回答一个不同的设计问题。

| 样本组 | 需要覆盖的差异 | 可能的资料入口 |
| --- | --- | --- |
| 文本与推理 | 普通生成、推理预算、工具和结构化输出组合 | Google、Anthropic、DeepSeek、OpenAI 官方资料 |
| 多平台同模型 | 同版本在两个平台的接口与限额差异 | 官方发布页、OpenRouter、models.dev |
| 图像与视频 | 输入、生成、编辑、长度与分辨率限制 | Google、BFL、fal、Replicate、官方模型卡 |
| 音频 | ASR、TTS、实时会话及编码限制 | Mistral、Google、官方语音模型文档 |
| embedding 与 rerank | 模态、维数、文档批次与截断 | Cohere、Jina、官方模型卡 |
| 开源衍生关系 | 基础版、微调、adapter、量化、合并 | Hugging Face、ModelScope |
| 专业模型 | 至少一个视觉感知、3D、时序或科学模型案例 | 发布方文档、任务目录、模型卡 |

至少纳入一组滚动别名、一处来源冲突、一条无法确认的特例，以及一个已停止提供的服务条目。
这些样本是下一阶段建议，本轮未将它们登记为正式数据集。

阶段二完成条件：每类样本能表达身份、任务、作用域、证据和缺失信息；冲突不被隐藏；修改限制时 diff 可审查。
通过后再把讨论稿收敛成 schema v0.1，确定保留哪些条件词汇。
